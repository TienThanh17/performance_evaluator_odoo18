# Role

# Context (Bối cảnh hiện tại & Vấn đề)
- Hiện tại, cấu hình biểu đồ (như `dashboard_enabled`, `dashboard_provider_key`, `dashboard_chart_type`, `kpi_behavior`) đang nằm ở model `hr.kpi.data.source` (Nguồn dữ liệu KPI).
- Vấn đề: Việc để cấu hình ở Data Source khiến hệ thống không thể tạo các biểu đồ tổng hợp (Macro) cho các KPI định tính/nhập tay, đồng thời gây khó khăn trong việc tách biệt Dashboard Cá nhân và Dashboard Phòng ban.
- Model `hr.kpi.dashboard.widget` hiện tại đang có sẵn các trường cấu hình nhưng chưa được áp dụng triệt để.

# Target (Mục tiêu Refactor)
Chuyển toàn bộ quyền kiểm soát việc vẽ biểu đồ về model `hr.kpi.dashboard.widget`. 
Đạt được 3 mục tiêu:
1. Tách biệt Dashboard Cá nhân và Phòng ban (Dựa vào `dashboard_kind`).
2. Hiển thị Chart KPI của riêng Phòng ban (Sử dụng loại `micro` widget).
3. Chart so sánh/xếp hạng các nhân viên trong phòng ban (Sử dụng loại `macro` widget).

## Bước 3: Refactor Backend Logic (Service)
Sửa lại hàm trả dữ liệu biểu đồ (ví dụ `build_dynamic_charts` trong `hr_kpi_dashboard_chart_service.py`).
Hàm này nhận tham số `evaluation` (phiếu đánh giá hiện tại) và `dashboard_kind` ('individual' hoặc 'department').

Logic xử lý tuần tự qua các widgets:
```python
def build_dynamic_charts(self, evaluation, dashboard_kind='individual'):
    charts = []
    # 1. Tìm các widget đang active và đúng mặt trận (dashboard_kind)
    widgets = self.env['hr.kpi.dashboard.widget'].search([
        ('active', '=', True), 
        ('dashboard_kind', '=', dashboard_kind)
    ], order='sequence')
    
    for widget in widgets:
        # 2A. Xử lý MICRO WIDGET (Biểu đồ chi tiết cho 1 chỉ tiêu)
        if widget.widget_class == 'micro' and widget.data_source_id:
            # Tìm KPI line trong phiếu đánh giá map với data source này
            matched_line = evaluation.evaluation_line_ids.filtered(
                lambda l: l.data_source_id.id == widget.data_source_id.id
            )
            if matched_line:
                # Code gọi các hàm build chart cũ (vd: _build_generic_target_actual_bar), 
                # nhưng tham số cấu hình (chart_type, behavior) lấy từ `widget` thay vì `data_source`
                chart_data = self._build_micro_chart_for_line(evaluation, matched_line[0], widget)
                if chart_data: charts.append(chart_data)
                
        # 2B. Xử lý MACRO WIDGET (Biểu đồ tổng hợp)
        elif widget.widget_class == 'macro':
            # Giải quyết bài toán 3: Phân phối / Xếp hạng nhân viên cho Dashboard Phòng ban
            if widget.macro_widget_type == 'distribution' and dashboard_kind == 'department':
                domain = [
                    ('department_id', '=', evaluation.department_id.id),
                    ('date_from', '=', evaluation.date_from),
                    ('date_to', '=', evaluation.date_to),
                    ('state', '=', 'done')
                ]
                employee_scores = self.env['hr.kpi.evaluation'].read_group(
                    domain=domain,
                    fields=[f"{widget.measure_field or 'final_score'}:avg"],
                    groupby=[widget.group_by or 'employee_id']
                )
                labels = [item.get('employee_id')[1] if item.get('employee_id') else 'Unknown' for item in employee_scores]
                data = [item.get('final_score') for item in employee_scores]
                
                charts.append({
                    "chart_type": "bar",
                    "chart_data": {
                        "labels": labels,
                        "datasets": [{"data": data, "label": "Điểm KPI", "backgroundColor": "#3b82f6"}]
                    },
                    "chart_meta": {"title": widget.name}
                })
            # ... (Các logic macro khác như radar, trend line)
            
    return charts

```
